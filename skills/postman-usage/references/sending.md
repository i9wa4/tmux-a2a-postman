# postman-usage — sending

## 1. Sending and session work

Use `tmux-a2a-postman help send-heredoc` for every ordinary send. Use
`tmux-a2a-postman skills postman-usage session-flow` after sends and during live
mailbox work. Read own sent and already-claimed read files directly when needed;
do not bypass POP by opening unclaimed inbox bodies. For restart/compaction
recovery, use `tmux-a2a-postman skills postman-recall guide` before resuming
live mail work.

Read mandatory send/POP self-state: node, unread/inbound/outbound/draft/failed
counts, last successful POP/capture/screen-change times and as-of evidence.
Missing or failed diagnostics mean unknown.
