# Review report

Report important findings supported by inspected evidence. Prefer a few strong
findings to speculative feedback. Include minor suggestions or praise only when
requested or materially useful; the annotation list is not a quota.

Each perspective reviewer annotates a finding when reporting it. Give the
observation, inspected evidence and affected location or an explicit non-file
source, impact, recommended response when needed, material uncertainty, and
actual originating `<coordinator>:<perspective>` labels. Do not invent
coordinates or certainty.

The final integrator reconciles conflicting evidence and annotations against the
agreed criteria during the single synthesis. When findings merge, retain the
union of actual originators without duplicates in every rendering, including PR
drafts. Collecting, verifying or editing alone does not confer authorship.

| Annotation | Meaning                                                       |
| ---------- | ------------------------------------------------------------- |
| `[must]`   | Required before accepting the result; for a PR, before merge. |
| `[want]`   | Strongly recommended, but not blocking.                       |
| `[imo]`    | Optional opinion or alternative.                              |
| `[nits]`   | Minor style or readability improvement.                       |
| `[ask]`    | Clarification needed.                                         |
| `[fyi]`    | Relevant information; no action requested.                    |
| `[praise]` | Specific positive feedback; no action requested.              |

State the reviewed target and revision, actual coverage, inaccessible evidence,
unperformed checks and material limits. No supported findings and incomplete
verification are different outcomes. Honor the requested format and language. A
review conclusion grants no publication, execution or risk-acceptance authority.
