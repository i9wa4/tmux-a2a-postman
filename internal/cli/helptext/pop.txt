pop — claim and archive one own unread message

Usage:
  tmux-a2a-postman pop [--capture-related-panes] [exact-message-id]

Options:
  --capture-related-panes       Supplemental sender/receiver evidence
  --config <absolute-path>      Explicit postman.md override
  --postman-md <absolute-path>  Alias for --config

Returns JSON. status=message includes message metadata,
markdown_absolute_path, pop_receipt_absolute_path, and mandatory self-state.
status=empty still includes self-state. The selected ID, if supplied, must
identify an eligible own unread message; POP never drains another role.
The archive path is openable on return and the .pop.json receipt is durable.

Read the complete archived Markdown body through EOF before handling,
routing, replying, deciding status, or deciding no action. The JSON does not
embed the body. A successful claim is not replayed on retry. An output failure
after a committed claim cannot recreate the inbox entry.

Native --capture-related-panes currently reports unknown/no text. It is
supplemental and cannot reverse a successful claim.
