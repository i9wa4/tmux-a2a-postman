tmux-a2a-postman — file-first tmux workspace mail

The four active workspace commands use private files and native tmux identity;
no Postman daemon is required. A configured postman.md supplies roles, edges,
and an optional command reviewer. Missing or ambiguous identity fails closed.

  send-heredoc  Publish separate receiver inbox and sender sent copies
  pop           Claim one own unread message and return its archive path
  get-status    Read own saved-file state without claiming mail
  execute-bash  Run Bash after the configured exact approval protocol
  notifier-script  Print Bash/Readline recipient setup for sourcing
  register-notifier  Register the existing Codex conversation or Bash hook
  version       Print build version JSON
  help [topic]  Show command help

Default topology: $XDG_CONFIG_HOME/tmux-a2a-postman/postman.md, or
~/.config/tmux-a2a-postman/postman.md when XDG_CONFIG_HOME is unset.
The four workspace commands accept an absolute --config or --postman-md.
Use quoted heredoc stdin for send-heredoc. Read a complete archived body
after every successful pop. Bare tmux-a2a-postman prints usage.

Receiving roles need runtime registration: help register-notifier.
