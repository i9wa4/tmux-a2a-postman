get-status-oneline — compact human overview of one tmux server

  tmux-a2a-postman get-status-oneline [--config <absolute-path>]

No positional arguments or command-specific options. TMUX selects the native
server; TMUX_PANE is not needed. Both getters read the same saved snapshot.
For a tmux #() job, pass its actual socket explicitly, for example:

  TMUX=/absolute/socket,PID,0 tmux-a2a-postman refresh-status
  TMUX=/absolute/socket,PID,0 tmux-a2a-postman get-status-oneline

External tmux status integration should refresh then render even when refresh
is busy or fails; quote actual native socket/PID and preserve stderr diagnostics.

Output is one line: [0]🟩💛:🟢 [1]⬛🟥
[N] is native session $N, sorted numerically. ':' separates included windows
in window-index order. Panes use physical top/left order within each window.

Shape: square = unread or inbound reply work (wins over outbound waits);
heart = only outbound reply waits; circle = all three counts zero.
Unknown/invalid required counts produce '?'. Draft/failed counts do not alter
this palette. A circle is not task completion or proof of a healthy process.

Color by age of last observed screen change, when capture is fresh:
  <1 minute       🟢 🟩 💚
  1–<5 minutes    🟡 🟨 💛
  5–<15 minutes   🟠 🟧 🧡
  >=15 minutes    🔴 🟥 ❤️
  unknown         ⚫ ⬛ 🖤

Capture freshness is independently fixed at less than 2 minutes. A capture
exactly 120 seconds old, missing baseline/comparison, invalid/future times or
replaced native pane makes activity unknown. Red means old observed screen
movement, not failure or a stopped agent. Equal samples do not prove continuous
inactivity. Screen movement can be a spinner or pasted input.

Rows with saved agent status produce glyphs. Unbound, dead, linked, renamed or
ambiguous role panes have unknown counts. Ordinary panes add no glyph; every
saved native session still displays its [N], including sessions without agents.
Missing/malformed/incompatible cache emits '?' and exits nonzero, with stderr.
Partial coverage and per-node uncertainty have stderr diagnostics. Valid stale
snapshots remain dated; current time only ages glyph color, never changes as_of.
--config is accepted but never read. No tmux, discovery, mail scan, state writes,
locks, invocation logs or hidden refresh occurs. Reading cannot verify a current
server incarnation. See help get-status and help refresh-status.

Emoji are emitted intact, including the red heart's variation selector.
Display width depends on tmux/terminal/font; no byte/column truncation is done.
