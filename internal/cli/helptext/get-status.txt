get-status — read own saved-file state

Usage:
  tmux-a2a-postman get-status [--config <absolute-path>]
  tmux-a2a-postman get-status [--postman-md <absolute-path>]

Returns JSON status=ok with self when saved evidence is sound. self includes
known, workspace, node, mailbox, as_of, unread, inbound and outbound exact
reply obligations, verified local peers, and next_action. Missing, damaged,
ambiguous, or busy state is unavailable, with a reason; unknown is never
reported as zero obligations.

This command reads saved files under a shared lock. It does not register
the caller, claim mail, notify panes, capture pane text, run Bash, or call
a daemon. It takes no positional arguments.
