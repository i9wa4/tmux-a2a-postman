Commands — file-first workspace surface

send-heredoc
  tmux-a2a-postman send-heredoc --to <node> [--reply-required|--no-reply]
  Accept a quoted heredoc on stdin. Optional: --reply-to <message-id>,
  --fills-input-request-id <input-id>, --capture-related-panes.
  Returns JSON with status, message, self, and separate notice outcome.

pop
  tmux-a2a-postman pop [--capture-related-panes] [exact-message-id]
  Claims own eligible unread message. Returns JSON with self and, when
  claimed, absolute archived Markdown and receipt paths.

get-status
  tmux-a2a-postman get-status
  Returns file-derived self-state. It does not POP or refresh pane evidence.

execute-bash
  tmux-a2a-postman execute-bash --command <bash>
  Streams Bash stdout/stderr. Writes Postman status JSON to stderr.
  Configured reviewer requires an exact file-mail approval reply.

All four commands accept an absolute --config or --postman-md path; otherwise
postman.md resolves from XDG_CONFIG_HOME or HOME/.config. No command accepts
a daemon context ID. Bare tmux-a2a-postman prints usage.

Recipient setup:
  Run register-notifier --runtime codex from each existing Codex conversation.
  Optional Bash automation uses notifier-script. See help register-notifier.
