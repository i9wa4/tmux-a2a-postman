Directories — private workspace mail

${XDG_STATE_HOME:-$HOME/.local/state}/tmux-a2a-postman/
  locks/<workspace>.lock           short interprocess workspace lock
  <workspace>/workspace.json      canonical original HOME-relative identity
  <workspace>/runtime/binding.json   replaceable native tmux binding
  <workspace>/runtime/notice-locks/<role>.lock   short paste/submit serialization
  <workspace>/runtime/notices/<id>.json        bounded notice attempt/receipt
  <workspace>/agents/<role>/
    draft/ inbox/ read/ sent/ failed/   independent private Markdown copies
    read/<message-id>.pop.json     durable POP claim receipt
    executions/                   command audit, never reusable authorization
    pane/                         optional bounded observations
  <workspace>/transactions/        interrupted mail operation recovery

Workspace names flatten the escaped HOME-relative root, not the session name.
A live independent session cannot mutate another session's workspace.
Commands create required directories on first use; get-status never initializes.
