# help — command documentation

```sh
tmux-a2a-postman help [topic [reference]]
```

Core topics: send-heredoc, pop, get-status, execute-heredoc, approve-execution,
decline-execution. Configuration: config, directories. Other topics:
launch-agents, commands, messaging, version, help. No Postman daemon or startup
command is needed.

Workflow topics use their Skill names, such as `postman-plan` when installed.
Read the topic first, then each matching reference in its table with
`tmux-a2a-postman help <name> <ref>`. Names omit paths and file extensions.
