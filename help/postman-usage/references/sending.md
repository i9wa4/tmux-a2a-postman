# postman-usage — sending

## 1. Sending and session work

The ordinary-send procedure, including exact replies, is
`tmux-a2a-postman help postman-send-message sending`. Use
`tmux-a2a-postman help postman-usage session-flow` when reconciling live
mailbox obligations. Read own sent and already-claimed read files directly when
needed; do not bypass POP by opening unclaimed inbox bodies. For restart or
compaction recovery, use `tmux-a2a-postman help postman-recall guide` before
resuming live mail work.

Read POP self-state: node, unread/inbound/outbound/draft/failed counts, last
successful POP/capture/screen-change times and as-of evidence. Interpret each
send result, notification and send self-state through
`tmux-a2a-postman help postman-send-message outcomes`. Missing or failed
diagnostics mean unknown.
